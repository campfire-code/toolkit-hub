## B. 工程选型
- 桌面：Tauri 2（112.1k，Apache；tauri-action 出包；externalBin 挂 sidecar）为默认；Python 能力用 PyInstaller（产物许可证不受限）打成 sidecar；必须内嵌 Node/Playwright 的用 Electron + electron-builder。Wails 无官方出包 Action。体积量级（未实测）：Tauri 几~十几 MB，Electron 80–150MB；AI 模型首次运行下载，不打进包。
- 手机：手机跑不了 Python → 调云端 API；优先做成小程序页面；必须原生用 Capacitor（复用 Web 前端）或 Flutter。
- macOS：Apple Developer 99 美元/年，一个账号签全部；不签名时 Sequoia 起须进「隐私与安全性 → 仍要打开」。
- Windows：不签名 SmartScreen 拦截；SignPath Foundation 免费（OSI 许可证、全自动构建、公开签名策略，发布者显示 SignPath Foundation）；Azure Artifact Signing 约 9.99 美元/月（第三方报道，中国大陆主体资格未核实）。
- 多仓库：模板仓库 + 中心 `ci` 仓库复用工作流（workflow_call）+ tag 触发矩阵出包传 Releases + 汇总仓库定时生成目录 README 与 catalog.json。参考：PowerToys、it-tools、CyberChef、awesome-tauri。
- 许可证：我们用 MIT；fork GPL → 该工具改 GPL；AGPL 部署成服务也要给源码；LGPL/MPL 只管改动文件；非商用/无许可证只借思路。每仓附 THIRD_PARTY_LICENSES。
