# 术语表（界面与上架文案只用中文）

用户 2026-10-24 要求：产品里只能有中文。给用户看的文字一律用中文，包括界面、提示、报错、示例数据和上架图。`scripts/check-zh.mjs` 按本表检查。

## 保留原文

下面这些词保留原文，其余英文都要换成中文。

- **文件格式和单位：**
  - 文档：`PDF` `Excel` `Word` `PPT` `CSV` `TXT` `JSON` `Markdown` `HTML` `SRT` `ZIP` `OFD` `XLSX` `DOCX` `PPTX` `MD` `DOC` `XLS`
  - 图片：`PNG` `JPG` `JPEG` `WebP` `BMP` `GIF` `SVG` `HEIC` `ICO`
  - 音视频：`MP4` `MP3` `WAV` `MOV` `M4A` `WebM` `MKV` `AVI` `ProRes` `VP9` `MKV` `AVI` `M4V` `FLV` `AAC` `FLAC` `OGG` `WEBM` `AMR`
  - 单位：`KB` `MB` `GB` `px` `ms` `fps` `dpi` `DPI` `mm` `Hz`
  - 纸张规格：`A4`
- **平台与产品名**（没有通行中文名的）：
  - 系统：`Windows` `macOS` `Mac` `Linux` `iOS` `Android`
  - 工具和服务：`Chrome` `Docker` `TikTok` `Shop` `Shopee` `Amazon` `FBA` `SP-API` `Lazada` `Temu` `ASIN` `SKU` `GitHub` `Claude` `ChatGPT` `DeepSeek` `OpenAI` `Ollama` `OCR` `BiRefNet` `birefnet-lite-512` `model.onnx`
  - 泛称：`AI` `App` `API` `ID` `WPS`
- **官方字段名：**用户必须照着平台后台填写的字段，第一次出现时要在后面加中文说明，例如「AppID（小程序 ID）」。
  - 微信小程序：`AppID` `AppSecret` `openid`
  - OFD 文件内部的固定名称：`OFD.xml` `DocRoot`（只在「文件损坏」类报错里出现，第一次出现时后面加中文说明）
- 词库文件（JSON）里的字段名：`words`（自定义词）`whitelist`（白名单），只在「导入词库文件失败」的报错里出现，后面加中文说明。
- 群机器人消息 JSON 里的字段名和取值（企业微信 / 钉钉 / 飞书群机器人调试器的格式提示、模板名里出现，用户必须照着写进 JSON）：`msgtype` `content` `mentioned_list` `userid` `title` `description` `link` `links` `card` `post` `tag` `text` `at` `img` `news` `info` `comment` `warning` `btns` `btnOrientation` `isAtAll` `card_type` `text_notice` `news_notice` `main_title.title` `sub_title_text` `card_action.type` `image_key` `zh_cn` `en_us` `errmsg` `FeedCard` `ActionCard` `Content-Type` `md5` `base64` `timestamp` `UTF-8` `SEC` `POST` `interactive` `data` `image` `all` `true` `false`
- Shopee 开放平台：`Partner`（Partner ID、Partner Key，第一次出现时后面加中文说明「合作方编号」「合作方密钥」）
- 亚马逊卖家授权：`LWA`（LWA Client ID、LWA Client Secret，第一次出现时后面加中文说明「客户端编号」「客户端密钥」）`Client` `Refresh` `Token`（Refresh Token，后面加「刷新令牌」）
- TikTok Shop 开放平台：`Center`（Partner Center，后面加「合作伙伴中心」）`Service`（Service ID，第一次出现时后面加「服务编号」）
- 抖店等平台的同类字段：`App Key` `App Secret` `Key` `Secret` `access_token`
- **技术地址：**`URL` `HTTP` `HTTPS` `IP` `op.jinritemai.com`（抖店开放平台网址，前面必须写明「抖店开放平台网址」）。界面里优先写「网址」「地址」。
- **颜色代码示例：**界面里举例的颜色代码（井号加六位十六进制）：`F5F5F5` `FFFFFF`。
- **复制和打码时显示的原样数据**（例如接口返回的 errcode 数值、JSON 正文）不算界面文字，但标签要用中文。

## 常见替换

| 英文 | 改成 |
|---|---|
| Webhook | 回调地址 / 机器人地址 |
| errcode / errmsg | 错误码 / 错误说明 |
| token | 令牌（官方字段名除外） |
| prompt | 提示词 |
| model | 模型名 |
| Base URL / endpoint | 接口地址 |
| API Key | 密钥 |
| OK / Done | 完成 |
| Loading | 加载中 |
| Error | 出错 |
| demo / sample | 示例 |
| preview | 预览 |
| export / import | 导出 / 导入 |
| copy | 复制 |
| Tab / Enter / Ctrl | 用按键符号：⇥ / 回车 / Ctrl 保留（键盘上印的就是 Ctrl） |

## 示例数据

示例数据用真实感的中文。店名、商品名、人名、群名都写中文，不写 `Sample` `Test` `foo` 这类英文。
