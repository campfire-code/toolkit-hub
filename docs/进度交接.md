## 今天修过的坑

- **工具名带 `/` 或 `&`**：发布说明模板里的 sed 会出错。已在四个流程里先转义。
- **误带 ffmpeg**：9 个不处理音视频的工具误带了 ffmpeg 打包声明，导致出包失败。已删掉；`release-tool` 发版前会检查这一项。
- **认错运行**：`release-tool` 曾把同一标签上一次失败的运行当成这次的。现在只认推送之后新建的运行。
- **launcher 打包重复**：打包时会把 `campfire/` 目录也打进去。已去掉。
- **w05 日志泄露密钥**：上游启动日志明文打印企微 secret 和 aes_key。已在 fork 里改掉；fork 说明里已加上「检查日志是否打印密钥」这一步。
