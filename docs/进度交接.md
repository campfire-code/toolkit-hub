## 复用流程（`.github/workflows/`，打 `v1` 标签）

改了工作流以后要运行：`git tag -f v1 && git push -f origin v1`

| 流程 | 用途 |
|---|---|
| `tauri-release` | 自研桌面工具，出三平台安装包 |
| `tauri-check` | 类型检查与测试 |
| `mirror-release` | fork 工具转发布上游安装包 |
| `launcher-release` | Python 类 fork 的双击启动包。**打包时会删掉 `campfire/` 目录**，启动脚本调用的辅助脚本要放仓库根目录 |
| `docker-release` | 服务端类 fork，发布镜像和部署文件。**新镜像默认私有，要在网页上手动设为 Public** |
| （无复用）油猴脚本 | e22 自带 release.yml，`delivery: userscript` |

## 脚本（`scripts/`）

| 脚本 | 用途 |
|---|---|
| `new-tool.mjs <编号> [--ffmpeg]` | 从模板生成工具。**只有音视频工具才加 `--ffmpeg`** |
| `check-tools.mjs <编号...> --build` | 类型检查、测试、构建 |
| `shot.mjs` / `make-icon.mjs` | 截图（标准 2080 宽）/ 生成图标 |
| `publish-tool.mjs` / `publish-fork.mjs` | 推送自研 / fork 工具。fork 只有 `delivery = desktop` 才生成篝火图标 |
| `release-tool.mjs` / `release-many.mjs` | 发版。重发：`gh release delete <tag> -R <repo> -y --cleanup-tag`、删本地标签，再推送、发版 |
| `sync-status.mjs` | 以 GitHub 实际发布为准刷新状态 |
| `gen-listing.mjs` | 生成应用区上架材料 |
| `sync-kit.mjs` | 同步模板框架。会覆盖 capabilities；e32、c06、c10 自加了 `fs:allow-remove`，c29 加了 `fs:allow-copy-file` 和 yt-dlp shell scope，同步前先 diff |
| `gen-catalog.mjs` / `gen-docs.mjs` | 生成总目录 / README。修正表 `DESC_FIX`、`NO_UPSTREAM`（含 7 个改自研的）、`UPSTREAM_FIX`（a01 c06 e05 o16 o17 c10 c29 等）；`UITYPE` 已补 7 个改自研的 |
